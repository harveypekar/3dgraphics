# Introduction to 3d graphics with Unity 3D

## Getting ready

Download and install Unity from https://unity.com/download. After installation, start up the unity hub. You will be faced with the following prompt asking you to login:

Unfortunately, this is mandatory, so make an account and login. Afterwards you should see the following screen: 

It's telling us that we don't have any versions of Unity installed yet. Confusingly, we didn't install Unity, we installed Unity Hub, which manages projecd and different version of Unity. Amazing. Go ahead and install the version of Unity that it proposes.


Download and install Renderdoc from https://renderdoc.org/.
